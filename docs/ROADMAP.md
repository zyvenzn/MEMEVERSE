# MEMEVERSE implementation roadmap

## Phase 1 — Foundation (in progress)
- [x] Repository starter UI
- [x] Supabase project configuration template
- [x] Player profiles and one-time virtual starter grant migration
- [x] Wallet/ledger row-level security baseline
- [x] Basic social feed tables and policies
- [ ] Apply migration to a Supabase project
- [ ] Connect frontend authentication and session handling

## Phase 2 — Shared online economy
- [ ] Trusted server-side ledger transaction function
- [ ] Transaction idempotency and audit tests
- [ ] Player inventory and virtual purchases
- [ ] Realtime profile/feed updates

## Phase 3 — Social applications
- [ ] X-style follows, likes, comments, reposts, DMs
- [ ] Telegram-like chats, groups, channels, fictional number inventory
- [ ] Discord-like servers, roles, permissions, text channels

## Phase 4 — Markets and creator economy
- [ ] Simulated token launchpad and bonding curve
- [ ] Anti-wash-trading and creator reward rules
- [ ] Marketplace listings, escrow, delivery and disputes
- [ ] Licensed market data integration and simulated trading

## Phase 5 — Release readiness
- [ ] Moderation, reporting and account safety
- [ ] Load, security and migration tests
- [ ] Monitoring, backups and recovery
- [ ] Mobile PWA installability and accessibility

All trading and rewards remain virtual-only unless a separate, legally reviewed
product decision changes that scope.
